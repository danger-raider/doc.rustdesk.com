Скористайтеся цими посібниками для Windows, щоб установити RustDesk, підготувати пакет або розгорнути клієнт Windows, а також налаштувати MSI чи підвищення привілеїв у портативному режимі в керованих середовищах.

## Який посібник для Windows обрати?

| Потреба | Найкращий посібник |
| --- | --- |
| Стандартне встановлення клієнта Windows | [Огляд клієнта Windows](/docs/uk/client/windows/) |
| Кероване розгортання, тихе встановлення або пакування | [MSI](/docs/uk/client/windows/msi/) |
| Портативний режим із підтримкою підвищення привілеїв | [Підвищення привілеїв у портативному режимі Windows](/docs/uk/client/windows/windows-portable-elevation/) |

## Короткі відповіді для Windows

- Для більшості кінцевих користувачів використовуйте стандартний інсталятор.
- Для корпоративного розгортання та сценаріїв автоматизованого встановлення використовуйте посібник MSI.
- Використовуйте підвищення привілеїв у портативному режимі, якщо в portable-режимі потрібна робота з адміністративними запитами.
- Якщо ви використовуєте власний сервер, поєднуйте ці інструкції з розділом [Розгортання клієнта](/docs/uk/self-host/client-deployment/) для серверних параметрів розгортання.
