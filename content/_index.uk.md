RustDesk — це повнофункціональна альтернатива програмам віддаленого керування з відкритим кодом, орієнтована на самостійне розгортання та безпеку з мінімальним налаштуванням. Ви повністю контролюєте свої дані. Клієнт має відкритий код, а для серверної частини можна обрати повнофункціональний **Professional Server**, доступний для придбання на нашому [вебсайті](https://rustdesk.com), або базовий безкоштовний сервер з відкритим кодом, створений на основі **Professional Server**.

## Який варіант RustDesk обрати?

| Потреба | З чого почати |
| --- | --- |
| Використовувати RustDesk як кінцевий користувач або адміністратор | [Клієнт](/docs/uk/client/) |
| Самостійно розгорнути безкоштовний сервер з відкритим кодом | [RustDesk Server OSS](/docs/uk/self-host/rustdesk-server-oss/) |
| Самостійно розгорнути сервер із вебконсоллю, SSO та корпоративними засобами керування | [RustDesk Server Pro](/docs/uk/self-host/rustdesk-server-pro/) |
| Зібрати або запакувати RustDesk з вихідного коду | [Розробка](/docs/uk/dev/) |

## Можливості
- Працює у Windows, macOS, Linux, iOS, Android і Web.
- Підтримує програмні кодеки VP8 / VP9 / AV1 та апаратні кодеки H264 / H265.
- Дає змогу контролювати власні дані та легко розгорнути self-hosted рішення у своїй інфраструктурі.
- P2P-з'єднання з наскрізним шифруванням на основі NaCl.
- У Windows не потрібні права адміністратора або встановлення; за потреби привілеї можна підвищити локально або віддалено.
- Ми прагнемо зберігати простоту й спрощувати все, що можна спростити.
